# うりりのお掃除（ニコおじ大爆発）

ボンバーマン風のブラウザゲームです。主人公「うりり」が爆弾で「ニコおじ」をやっつけて、散らかった畳部屋をお掃除します！

## 遊び方
ブラウザで `index.html` を開くだけ（インストール不要）。

| 操作 | 内容 |
|---|---|
| 矢印キー / WASD | 移動 |
| 左クリック | 爆弾を置く |
| 右クリック | 起爆（起爆リモコン取得時）|
| Enter | スタート / 決定 |
| P | ポーズ |

- 全5ステージ＋ボス戦（巨大ニコおじ）＋クリア後のボーナスステージ
- アイテムでパワーアップ（火力・爆弾数・スピード・起爆リモコン・残機）
- 障害物の同時破壊や寿司アイテムでスコアアップ！
